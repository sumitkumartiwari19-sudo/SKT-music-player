# 🎵 SKT Music Player

A modern, fast, and lightweight offline music player for Android.

## ✨ Features

- 🎧 Play all popular audio formats
- 📂 Automatic music scanning
- 🔍 Fast song search
- ❤️ Favorites playlist
- 📜 Lyrics support
- 🎨 Modern Material Design UI
- 🌙 Light & Dark Theme
- ⚡ Smooth animations
- 📱 Optimized for Android devices
- 🚫 Offline playback (No internet required)
